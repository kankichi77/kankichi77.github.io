# kankichi77.github.io

A small personal website: [kankichi77.github.io](https://kankichi77.github.io)

The home page is a simple menu of the pages below.

## Pages

- **[Home](https://kankichi77.github.io/)** — Hello you. Links to everything else.
- **[HKU Catering](https://kankichi77.github.io/hku/)** — Campus restaurants you can order from online. Tap a place to open its order page.
- **[Math](https://kankichi77.github.io/math/)** — Papa's さんすうドリル, a simple arithmetic practice set.
- **[Typing](https://kankichi77.github.io/typing/)** — A short typing practice game.
- **[Learn to Code](https://kankichi77.github.io/learntocode/)** — A beginner HTML sample for learning the basics.

Each of those lives in its own folder (`hku`, `math`, `typing`, `learntocode`).
